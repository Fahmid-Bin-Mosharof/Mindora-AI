# Mindora AI — Personal AI Study Workspace (Frontend)

Polished, production-ready React frontend for Mindora AI. The UI is fully built and ships with a built-in **mock backend adapter** so you can demo it standalone, then point it at your own **FastAPI + MongoDB** backend by setting one environment variable.

## Stack
- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui (custom dark-AI design system)
- React Router, React Query, Framer Motion
- i18next (English + Bengali, font auto-swaps to Hind Siliguri for `bn`)

## Pages
- `/` Landing (hero + features)
- `/signup`, `/login` Auth
- `/dashboard`, `/library`, `/upload`, `/profile` (protected)
